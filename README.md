# SomaFM for Windows

An independent Windows client for SomaFM internet radio. The application is a WPF project using LibVLC for live audio playback and a notification-area icon for quick controls.

Build and run on Windows with the .NET 8 SDK:

```powershell
dotnet run --project .\SomaFM.Windows\SomaFM.Windows.csproj
```
